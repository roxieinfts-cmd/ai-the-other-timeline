# AFTER SCHOOL

A buildless HTML/CSS/JavaScript interactive narrative prototype.

## Run locally

Serve `dist/` with any static web server. The game has no build step and no backend.

## Content

- `dist/content.js` contains locations, events, choices and endings.
- `dist/game.js` contains state, routing, save/load and ending logic.
- `dist/styles.css` contains the responsive pixel-campus interface.
- `dist/assets/` contains original generated scene art.

## Current vertical slice

- One Monday afternoon
- Campus map exploration
- Library, basketball court, home and phone interactions
- Time, project, connection and personal state
- Delayed consequences and six ending routes
- Browser-local save state
- Desktop and mobile layouts

The story and its numerical effects are fictional design assumptions. No live AI or real student assessment is used.
